## 通用 Lean 证明题规约 Skill

- 位置：`D:\lean4-harness-plugin\skills\lean-problem-formalizer\SKILL.md`。
- 用途：将当前用户输入的自然语言数学题忠实规约为待 Lean 验证的任务说明；明确变量、类型、量词、定义、前提、结论、歧义处置和验证闭环。
- 边界：不内置或偏向任何固定数学题，不替用户改变题意，也不把未经 `lean_check` 验证的内容标记为证明完成。
- 题源核对：当图片、扫描件、PDF 或 OCR 转写并存时，先核对上标、下标、分数、符号、端点和量词；清晰原题与转写冲突时以原题为准，无法识别时要求用户补充，禁止凭猜测形式化。
- 部署：`scripts\Install-LeanProblemFormalizerSkill.ps1` 将唯一源文件安装到隔离 `DSH_HOME\skills`，由标准 Web Agent 的默认 Skill 发现机制加载；实际 Harness 发现测试已确认其来源为 `user-dsh`、模型和用户均可调用。已有不同内容的目标文件必须显式 `-Force` 才会覆盖。
